# homebrew-jovianops

Homebrew tap for JovianOps projects.

## Install

```bash
brew tap JovianOps/homebrew-jovianops
brew install gpuunlock
brew install cortex
brew install smartshell
```

## Formulae

| Formula | Description |
|---------|-------------|
| `gpuunlock` | GPU tuning dashboard (clock locking, undervolting, stress testing) |
| `cortex` | 10 Hermes skills bundle |
| `smartshell` | Expressive terminal with AI integration |
